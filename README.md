# Aurelia | Skincare Information Website

Aurelia Botanics is a responsive, educational skincare website designed
to make everyday skincare knowledge easier to understand. Instead of
selling products, the website provides beginner-friendly information
about skincare essentials, common ingredients, skin types, and simple
daily routines.

## Project Overview

The website uses a calm, nature-inspired visual style with warm neutral
backgrounds, forest-green accents, and terracotta details. It combines
editorial-style photography with clear sections and straightforward
explanations.

### Website Sections

-   **Home:** Introduces Aurelia Botanics and guides visitors to the
    main learning sections.
-   **About:** Explains the purpose of the website and its focus on
    accessible skincare education.
-   **Skincare Basics:** Covers three everyday essentials: cleansing,
    moisturising, and sun protection.
-   **Ingredient Library:** Introduces commonly used skincare
    ingredients, including hyaluronic acid, niacinamide, salicylic acid,
    vitamin C, ceramides, and aloe vera.
-   **Skin Types:** Describes normal, dry, oily, combination, and
    sensitive skin.
-   **Everyday Routine:** Provides a simple overview of morning and
    evening skincare steps.
-   **Frequently Asked Questions:** Answers common beginner questions
    about skincare.
-   **Contact:** Includes a demonstration contact form for visitors to
    submit a question.

## Technologies Used

-   **HTML5** for the page structure and content.
-   **CSS3** for the custom design, layout, and responsive styling.
-   **JavaScript** for interactive behaviour.
-   **Bootstrap 5** for the responsive navigation, grid layout,
    accordion, and interface components.
-   **Bootstrap Icons** for interface icons.
-   **Google Fonts** for typography.
-   **Unsplash** for remote skincare photography.

## How to Run the Website

1.  Download and extract the project folder.
2.  Open the folder in Visual Studio Code or another code editor.
3.  Open `Aurelia(project-3).html` in a browser.

For a convenient development workflow, install the **Live Server**
extension in Visual Studio Code, right-click `Aurelia(project-3).html`, and select
**Open with Live Server**.

An internet connection is required to load the Bootstrap CDN files,
Bootstrap Icons, Google Fonts, and Unsplash images.

## Main Features

-   Responsive layout for desktop, tablet, and mobile screens.
-   Navigation links that move visitors to each website section.
-   Collapsible mobile navigation menu.
-   Bootstrap accordion for frequently asked questions.
-   Contact form with basic required-field and email input validation by
    the browser.
-   JavaScript confirmation message after the demonstration form is
    submitted.

## Contact Form Note

The contact form is a front-end demonstration only. It does not send,
store, or email submitted messages because no back-end service or
form-processing API is connected.

## Image and External Resource Note

The website loads photographs from Unsplash using remote image links. It
also loads Bootstrap, Bootstrap Icons, and Google Fonts from their
respective online CDNs. These resources may not appear when the website
is used offline.

## Educational Disclaimer

The skincare information on this website is general educational content
and is not a substitute for medical advice, diagnosis, or treatment.
Skin needs vary from person to person. Visitors with persistent
irritation, painful or severe acne, unusual skin changes, or other
concerns should consult a qualified healthcare professional or
dermatologist.

## Customisation

You can adapt the project by:

-   Editing the text and section content in `Aurelia(project-3).html`.
-   Changing colours, typography, spacing, and layout in `style.css`.
-   Updating form behaviour and navigation interactions in `script.js`.
-   Replacing the remote image links in `Aurelia(project-3).html` with your own
    appropriately licensed images.
